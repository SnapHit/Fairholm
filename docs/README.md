# Design briefs

The seventeen design briefs that define Fairholm belong in this directory. They are the authority
for every design question; `CLAUDE.md` at the repository root explains how code and briefs relate
and `DECISIONS.md` records every ambiguity resolved during the build.

The briefs, by filename:

- build-specification.md
- browser-game-architecture-brief.md
- interaction-session-and-persistence-brief.md
- feel-input-gesture-and-audio-brief.md
- session-map-and-economy-brief.md
- turn-queue-and-standing-orders-brief.md
- colonists-and-labour-brief.md
- remaining-systems-proposal.md
- rival-charters-brief.md
- military-and-revolution-brief.md
- difficulty-brief.md
- onboarding-and-first-session-brief.md
- art-direction-and-rendering-brief.md
- naming-and-vocabulary-brief.md
- setting-and-fiction-brief.md
- legal-distinguishability-constraint.md
- colonization-mechanics-brief.md (background only: the 1994 game we depart from, never a source of mechanics)

Copy them in from the project. Nothing else lives here.
